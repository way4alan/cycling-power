# PACE 沛速車隊隱私權政策

**生效日期：**2026-11-18  
**服務名稱：**PACE 沛速車隊（https://cycling-power.vercel.app，LINE LIFF）  
**資料控管者：**PACE沛速車隊  
**聯絡信箱：**thewayzstore@gmail.com  
**所在地：**臺灣

本政策說明我們如何蒐集、使用、儲存、刪除與保護你的個人資料，包括你選擇連結 Strava 後，我們經由 Strava API 取得的資料。使用本服務，即表示你已閱讀本政策。若你不同意，請不要連結 Strava，並可要求我們刪除資料。

本政策不會修改、抵觸或取代 [Strava Privacy Policy](https://www.strava.com/legal/privacy)。若本政策與 Strava 隱私權政策在「經由 Strava API 取得的資料」上有衝突，以 Strava 的隱私權政策為準。

我們依循適用的資料保護法律辦理，包括臺灣《個人資料保護法》，以及（在適用範圍內）歐盟 GDPR 與英國 UK GDPR。Strava API Policy 也要求開發者提供符合 GDPR／UK GDPR 的隱私權政策。

## 1. 我們蒐集哪些資料

### 1.1 你在 PACE 提供的資料

- 透過 LINE 登入取得的識別與基本資料（例如 LINE 使用者識別、顯示名稱、大頭貼，以 LINE 實際授權範圍為準）。
- 你在車隊 App 自行填寫或更新的資料，例如簡介、體重、PACE FTP、車輛與輪組、保養紀錄、報名與出席、公開設定。
- 你自願上傳或輸入的團騎相關內容（例如路線檔、備註）。

### 1.2 你連結 Strava 後，我們代表你向 Strava 取得的資料

只有在你按下「Connect with Strava」並在 Strava 的授權畫面同意之後，我們才會存取你的 Strava 資料。我們目前請求的授權範圍是 `activity:read_all` 與 `profile:read_all`。你可在 Strava 授權畫面取消部分範圍；我們會檢查實際取得的範圍，沒有授權的資料不會去讀。

可能取得的資料包括：

- 選手基本資料：Strava 選手識別、名稱、與騎乘相關的裝備列表，以及（在授權允許時）FTP。
- 活動資料：活動識別、名稱、類型、開始時間、移動／總經過時間、距離、爬升、裝置名稱、對應的裝備識別、用以判斷路線或完攀的軌跡資料（例如 polyline）。
- 授權本身：存取權杖與更新權杖、授權範圍、webhook 事件（新活動、活動更新或刪除、解除授權）。

我們不會向 Strava 寫入你的資料（不請求 `profile:write` 或 `activity:write`）。

### 1.3 自動產生的技術資料

為了讓服務運作，伺服器與後端供應商可能記錄必要的技術資料，例如請求時間、安全日誌與錯誤紀錄。我們不會把這些日誌拿來對你做廣告分析。

Strava 可能監控並蒐集其 API 的 Usage Data，並將其用於任何商業目的（包括改進 API 或 Strava 平台、開發者或使用者支援，以及確保你與我們遵守 Strava 條款）。我們依 Strava API Policy §6.5 在此告知這件事。

## 2. 蒐集方式

- 你在 PACE 自行輸入或上傳。
- LINE LIFF 登入與授權。
- 你透過官方「Connect with Strava」按鈕，在 Strava 完成 OAuth 授權。
- 授權後，我們以 Strava API 讀取你的選手資料與活動；可用 webhook 接收新活動、變更或刪除，也會在你要求時同步。
- 你第一次連結時，若你同意，我們會**一次性**掃描既有騎乘，只為了找出可能的個人完攀，每一項都要你確認才會發 PACE 徽章。

---

## 3. 使用目的

我們使用上述資料，只為了提供這項車隊服務：

- 讓你登入、辨識車隊成員身分，並顯示你的個人主頁與設定。
- 管理團騎報名、一鍵出席確認、徽章、車庫里程與保養提醒。
- 在**只有你本人看得到的畫面**比對你的 Strava 騎乘與團騎或完攀條件，並請你確認後，才寫成 PACE 自己的紀錄。
- 在你確認後，更新你存在 PACE 的 FTP。
- 處理你的中斷連結、刪除或客服請求，以及維護安全與排除故障。
- 遵守法律義務與 Strava API 條款（包括在你解除授權或刪除活動後，停止使用相關 Strava 資料）。

我們**不會**：

- 把某個隊員的 Strava 資料顯示給其他隊員。
- 把 Strava 資料（含衍生、彙整或去識別化後的資料）用於 AI／機器學習訓練、評估、運作或檢索增強。
- 出售 Strava 資料，或為了廣告、資料經紀而提供給第三方。
- 向使用者收取任何與 Strava API 功能有關的費用。

## 4. 儲存期限

- **Strava 原始資料與待確認項目**（例如暫存的活動名稱、時間、距離、軌跡、尚未確認的徽章／出席／FTP 提示）：只作為短期快取，**最多保留 7 天**，到期即刪除。若該筆資料已在 Strava 上被你刪除，我們會在收到通知後儘快移除，最遲在 48 小時內停止顯示或使用。
- **授權權杖**：只在你的 Strava 連結有效期間保存；中斷或撤銷後刪除。
- **你確認後的 PACE 紀錄**（例如已確認的出席、個人徽章、你同意寫入的 PACE FTP，以及你在車庫中確認記入的里程）：屬於你在車隊的紀錄，會保存到你要求刪除、或你的車隊帳號結束為止。
- **車隊帳號資料**（報名、個人主頁等）：在你仍為隊員期間保存；帳號刪除或你提出刪除請求後，依第 6 節辦理。

## 5. 誰會處理你的資料

我們使用下列受託處理者，以提供本服務。我們為他們的處理負責，並要求他們承擔不低於本政策的保護義務：

- **LINE**：登入與 LIFF 執行環境。
- **Supabase**：資料庫與後端函式。
- **Vercel**：網站託管。

這些處理可能在臺灣以外的地區進行。在適用 GDPR／UK GDPR 時，跨境傳輸將依相關標準契約條款或其他合法機制辦理。

除了上述為提供服務所必需的處理、法律要求，或你的明確指示外，我們不會把你的個人資料提供給其他第三方。我們不會把 Strava 資料轉給 AI 服務商。

若 Strava 向我們調取受託處理者名單，我們會依條款提供。

## 6. 你的權利與選擇

依適用法律，你可能享有下列權利：查閱、複製、更正、刪除、撤回同意、限制處理，以及向監督機關申訴（在臺灣可向個人資料保護的主管機關提出；若 GDPR 適用，可向你所在地的資料保護機關提出）。

### 6.1 如何查看你的資料

你可在 App 的「我的」、車庫、個人主頁與待確認畫面，查看我們為你保存的相關資料。你也可以寫信到 thewayzstore@gmail.com 請求一份你本人資料的副本。

### 6.2 如何撤回 Strava 同意並刪除 Strava 資料

你可以用任一方式撤回：

- 在 PACE 的 Strava 區塊按「中斷連結」；或
- 到你的 Strava 帳戶授權管理頁取消本 App 的存取：https://www.strava.com/settings/apps

中斷或撤銷後，我們會刪除連線、權杖、暫存活動與尚未確認的提示。我們會在 App 顯示書面確認；若你是在 Strava 端解除授權，我們會在你下次開啟 App 時顯示確認，或另以通知告知。依 Strava API Policy，這類刪除會儘快完成，最遲在 30 天內完成。

預設情況下，你**已經確認**的 PACE 出席、徽章與 PACE FTP 會留在車隊紀錄中，因為那是你本人在 PACE 做成的申報，不再是原始的 Strava 快取。若你希望連這些紀錄一併刪除，請按中斷連結後再寫信到 thewayzstore@gmail.com，或在信中直接提出，我們會一併處理。

### 6.3 如何請求刪除全部個人資料

請來信 thewayzstore@gmail.com，主旨或正文說明你要刪除哪些資料。我們會在合理期間內處理，並書面回覆結果。依法必須保留的資料（如有）會另行說明。

### 6.4 前往你的 Strava 帳戶

- 帳戶與隱私設定：https://www.strava.com/settings/profile
- App 授權管理：https://www.strava.com/settings/apps
- Strava 隱私權政策：https://www.strava.com/legal/privacy
